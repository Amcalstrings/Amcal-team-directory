# Amcal Team Directory

This is a shared project for practising collaboration with Git and GitHub.
Each student contributes a profile through a separate branch and PR

## How to Contribute

1. Clone this repo.
2. Create a branch for your profile
3. Add your profile inside the profiles folder
4. Commit and push your changes
5. Open a PR
6. Address review feeback if any
7. Update your local main branch after your contribution is merged
